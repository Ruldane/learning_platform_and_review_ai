# Phase 14 · IDE de projets Python

L’IDE conserve l’arborescence, les onglets, les notebooks et leurs résultats. Le Professeur
renvoie vers les fichiers du projet. Le terminal ouvre un pseudo-terminal Linux et reçoit
une saisie par ligne. Le notebook relance Python par cellule et propose de rejouer les
cellules précédentes. Les appels à OpenAI passent par le client Tremplin sur socket local
et suivent les plafonds de D243.

Sous Edge, le parcours clavier a créé, sauvegardé et rouvert un notebook. La revue a trouvé
un brouillon perdu lors d’un changement d’onglet. Le test ciblé a reproduit la perte avant la
correction et vérifie maintenant que le brouillon reste disponible. En recette Linux jetable,
une cellule a produit la sortie attendue par le lanceur réel du bac, avec un code de sortie nul.
