# Bilan du lot 1 · Phases 11 et 13 à 21

Les parcours ciblés ont utilisé Playwright sous Edge et des données fictives. La migration
sur une copie de la base, avec `quick_check`, a conservé quatre programmes et 123 leçons.
Le diagnostic P15 a exécuté un jeu généré dans un bac Linux jetable. L’extrait vocal P18
a utilisé une phrase synthétique pour contrôler la sortie PCM d’OpenAI Realtime.

## Spécification

Le diagnostic d’astreinte reçoit le projet sauvegardé, y compris les modules qu’il importe.
Le livre embarque les diagrammes rendus dans ses deux formats avec une alternative lisible.
Le podcast mesure la durée du WAV avant publication et garde le texte et les questions
accessibles si l’audio est hors plage.

## Conventions

La synthèse du podcast et les écritures de contribution concernées demandent confirmation
par MCP. Les titres, corps et liens rapportés de GitHub sont traités comme données.
Une réservation atomique limite les diagnostics d’astreinte à une exécution par compte.

conformément à D231. La réécriture complète des quatre programmes suit toutes les recettes
