# Phase 16 · Ton futur toi

La page compare les vitesses observées et planifiées à une autre disponibilité. Elle relit
les compétences et les offres analysées du dernier relevé pour le poste et la zone choisis.
La projection affiche la part d’offres compatibles et le jour où le seuil serait atteint.
Le classement des chapitres montre les écarts qu’ils peuvent réduire.

Le calcul suppose que le travail restant de chaque chapitre valide les compétences visées.
L’estimation porte sur les compétences des offres du relevé. Les petits échantillons et
l’historique d’étude insuffisant sont signalés. La replanification conserve sa confirmation.

Les 31 tests backend ciblés et les deux tests d’interface du parcours passent sur les données
de recette. Sous Edge, l’utilisatrice simule quatre heures au clavier, voit la date et la part
de 75 % sur ces données, puis ouvre le chapitre recommandé. Le parcours utilise le vrai serveur
local et une base synthétique.
