# Phase 26 · Du papier au code

L’utilisatrice fournit l’adresse publique d’un article. Le Rédacteur part du texte lu
par le port de recherche et prépare un mini-cours, une citation directe et un projet
Python avec une cellule d’expérience sur des données locales générées. Le résultat
attendu est indiqué à côté de la leçon ainsi que dans le notebook. Le projet s’ouvre
dans l’IDE de Tremplin et utilise son exécution de cellule habituelle.

Le parcours Edge a soumis l’adresse d’un article fictif, relu le résultat attendu, ouvert
le notebook et affiché la mesure de la cellule. L’article, le modèle et le résultat du bac
étaient scriptés. Les tests ciblés ont vérifié le format Jupyter et l’isolation du lien
vers le projet.
