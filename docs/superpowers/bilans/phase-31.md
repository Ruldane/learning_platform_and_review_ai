# Phase 31 · Course contre ton fantôme

Le quiz affiche la progression et le temps de jeu d’une tentative personnelle
comparable. L’IDE compare les résultats et la durée des vérifications du même
exercice. Les entrées du journal ouvrent la tentative associée, y compris
lorsqu’elle est antérieure aux douze dernières. Les tentatives anciennes
affichent les repères disponibles.

Un parcours Playwright sous Edge a ouvert le défi depuis le journal, sélectionné
une tentative et remis le nouveau quiz. Les tests ciblés ont vérifié la version
des questions, les données historiques et le cloisonnement. Voir D254.
