# Phase 27 · Veille des leçons

La veille rapproche les journaux de versions de la pile de lecture et les appels
réellement présents dans les exemples Python des leçons publiées. Une proposition
cite le journal de versions et présente les blocs concernés. Le bouton
d’acceptation déclenche la vérification de la leçon après contrôle de son
empreinte. La version publiée reste disponible pendant la vérification.

Les tests ciblés couvrent la détection, le regroupement de deux sources miroir,
la confirmation et le cloisonnement des comptes. Un parcours Playwright sous Edge
a vérifié l’apparition de la proposition, la lecture de l’ancienne version
et la publication après validation. Les journaux de versions et le Vérificateur
étaient scriptés.
