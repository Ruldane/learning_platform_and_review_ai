# Phase 38 · Profil LinkedIn

La proposition de titre, de résumé et de compétences s’appuie sur le profil
maître validé et les projets validés. Une offre facultative guide l’ordre des
faits retenus. Le contrôle partagé avec le CV signale les affirmations
non étayées. La copie de chaque partie s’active après enregistrement d’une
version sans signalement.

Le parcours Edge a détecté un chiffre fictif, modifié le résumé, vérifié
l’absence de signalement puis copié le texte dans un presse-papiers factice.
Les contrôles ciblés ont vérifié les compétences non prouvées, le cloisonnement
des comptes et les conflits de révision. Voir D263.
