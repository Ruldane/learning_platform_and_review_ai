# Phase 20 · Classe virtuelle

Depuis une leçon publiée, l’utilisatrice explique une notion à trois camarades de niveaux
différents. Les rôles et les sources restent enregistrés lors de la reprise du fil.

Le parcours Edge a repris une classe et vérifié les trois voix sur une API de recette avec
modèle scripté. Les tests ciblés couvrent également l’isolation, la persistance et le budget
commun du tour. D241 décrit la conservation de la source.
