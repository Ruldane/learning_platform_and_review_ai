# Phase 28 · Galaxie du savoir

La galaxie relie les compétences, les écarts du programme et les notes actives du
Cerveau. La projection Canvas et la liste au clavier partagent la sélection.
Une compétence ouvre un chapitre publié ou propose son sujet dans le training.
Le nom est relu dans le compte à l’ouverture du training à partir de
l’identifiant de la compétence.

Les tests ciblés couvrent les liens entre notes, leurs homonymes, les chapitres
publiés et le cloisonnement. Un parcours Playwright sous Edge a vérifié l’état
vide, l’indexation de notes fictives, le zoom, la rotation, la liste au clavier et
le sujet prérempli. Voir D253.
