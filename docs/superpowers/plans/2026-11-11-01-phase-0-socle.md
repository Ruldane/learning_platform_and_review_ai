# Phase 0 — Socle : plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Un dépôt qui démarre avec `docker compose up`, sert `/api/v1/health` au vert, et permet de saisir et tester une clé API depuis l'écran Réglages, sur une base de code découpée pour accueillir les 19 features sans retouche.

**Architecture:** Back FastAPI en monolithe modulaire (features + registres + fournisseurs derrière interfaces, composition dans `app/bootstrap.py`). Front React découpé en features déclarées par manifeste, un composant par dossier. Contrat unique entre les deux : `contracts/openapi.json`.

**Tech Stack:** voir le plan directeur. Pour cette phase : uv, FastAPI, SQLAlchemy 2 async, aiosqlite, Alembic, pydantic-settings, cryptography (Fernet), langchain-anthropic, langchain-openai, httpx, respx, import-linter, ruff, mypy · pnpm, Vite, React, TypeScript, Tailwind, shadcn/ui, React Router, TanStack Query, openapi-typescript, openapi-fetch, Vitest, Testing Library, MSW, ESLint (+ `eslint-plugin-boundaries`, `eslint-plugin-react`).

**Spec:** `SPEC.md` (sections 1, 11, 12, 13.1, 13.2, 14.3, 15.4, 16, 17.2, 18.1). Plan directeur : `docs/superpowers/plans/2026-11-11-00-plan-directeur.md`.

## Global Constraints

Celles du plan directeur s'appliquent toutes. Rappel des valeurs utilisées dans cette phase :

- 300 lignes par fichier, 50 par fonction, bloquant en pre commit.
- Erreurs : `{"error": {"code": str, "message": str (français), "details": dict | null}}`.
- Niveaux : `rapide`, `standard`, `fort`, `vision` ; défaut au premier lancement : Anthropic `claude-haiku-5-5` pour les quatre (à revérifier).
- Clé : chiffrée avec `APP_SECRET` (fichier généré au premier démarrage dans le volume `app_data`), affichée par ses 4 derniers caractères, jamais journalisée.
- Réglages par défaut (11.4) : 2 h du lundi au vendredi, 3 à 4 h le week end ; leçons en français ; recherche fr + en ; 3 tours ; 300 000 tokens ; brief 7 h ; bilan dimanche 18 h ; relances 7, 14, 21 jours ; guide de style vide.
- Services Docker et ports (16.1) : `frontend` 5173, `backend` 8000, `qdrant` 6333 (dashboard), `ollama`, `ollama-init`, `searxng`, `gotenberg:8` en réseau interne. Volumes `app_data`, `qdrant_data`, `ollama_data`.
- Origine CORS unique : `http://localhost:5173`.

## Review Focus

1. **`APP_SECRET` régénéré** (volume recréé) : les clés en base ne se déchiffrent plus. Attendu : l'app démarre, la clé apparaît « illisible, à ressaisir », la fabrique LLM renvoie `llm_key_unreadable`. → test en tâche 0.8.
2. **Fuite de clé** : la clé complète n'apparaît dans aucune réponse HTTP ni aucune ligne de journal, y compris en cas d'erreur du fournisseur. → tests en tâches 0.5 et 0.8.
