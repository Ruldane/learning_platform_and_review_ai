Les anciennes adresses restent accessibles. Les nouvelles adresses ci-dessous ouvrent les cartes des rubriques.
Les chemins qui contiennent un préfixe `:nom` attendent un paramètre. Le signe `?` indique un paramètre facultatif. « Intégré » indique une fonction ouverte depuis un autre écran.
